# Инфраструктура проекта "fin" на Terraform

Данный репозиторий содержит Terraform-скрипты для автоматического развертывания инфраструктуры в Yandex Cloud для проекта. Код разбит на независимые модули для обеспечения переиспользуемости и удобства поддержки.

## 📁 Структура проекта

Папка `fin` содержит следующие директории и файлы:

*   **app/** — Конфигурация для развертывания приложения.
*   **container_registry/** — Управление реестром Docker-контейнеров (Container Registry).
*   **lockbox/** — Интеграция с сервисом секретов (Yandex Lockbox) для безопасного хранения паролей и ключей.
*   **mysql_cluster/** — Создание и управление отказоустойчивым кластером управляемой СУБД MySQL.
*   **mysql_db/** — Инициализация баз данных и пользователей внутри кластера MySQL.
*   **vm/** — Конфигурация виртуальных машин (Compute Cloud).
*   **vpc/** — Настройка сети: виртуальные сети (VPC), подсети, таблицы маршрутизации и группы безопасности.
*   **cloud-init.yml.tpl** — Шаблон конфигурации Cloud-Init для автоматической инициализации ВМ при старте (установка пакетов, добавление SSH-ключей).
*   **main.tf** — Корневой файл конфигурации, объединяющий все модули.
*   **providers.tf** — Настройка провайдеров и версий Terraform.
*   **variables.tf** — Корневые переменные для кастомизации окружения.
*   **.tflint.hcl** — Конфигурация линтера TFLint для проверки качества кода.
*   **terraform-docs.md** — Автоматически сгенерированная документация по входам/выходам модулей.
*   **Screenshots.md** — Скриншоты, подтверждающие успешное развертывание и работу инфраструктуры.

## 🛠 Требования

Перед началом работы убедитесь, что у вас установлены:
1. [Terraform](https://terraform.io) (версии 1.12.0 или новее)
2. Настроенный доступ к облачному провайдеру (CLI и сервисный аккаунт с необходимыми правами)
3. Опционально: [TFLint](https://github.com/terraform-linters/tflint) и [Checkov](https://github.com/bridgecrewio/checkov) для проверки кода

## 🚀 Быстрый старт

### 1. Настройка переменных
Создайте файл `terraform.tfvars` на основе файла `variables.tf` и заполните обязательные параметры:
```hcl
cloud_id  = "your_cloud_id"
folder_id = "your_folder_id"
zone      = "ru-central1-a"
# Другие необходимые переменные...
```

### 2. Инициализация проекта
Загрузите необходимые плагины провайдеров и модули:
```bash
terraform init
```

### 3. Проверка кода и валидация
Рекомендуется запустить валидацию и линтер перед деплоем:
```bash
terraform validate
tflint --recursive
docker run --rm --tty --volume $(pwd):/tf --workdir /tf bridgecrew/checkov --download-external-modules true --directory /tf
```

### 4. Просмотр плана изменений
Посмотрите, какие ресурсы будут созданы, изменены или удалены:
```bash
terraform plan
```

### 5. Применение конфигурации
Разверните инфраструктуру в облаке:
```bash
terraform apply
```

### 6. Удаление инфраструктуры
Если ресурсы больше не нужны, их можно полностью удалить:
```bash
terraform destroy
```
